# Contracts as axioms over an uninterpreted function (UCLID5)

The architecture nuXmv could not support. Instead of injecting contracts as
`INVAR`s into a model that **encodes** the network, the network becomes an
uninterpreted function and each CROWN contract becomes a quantified **axiom**.
The solver never sees a ReLU.

```ucl
function ctrl(x : real, y : real) : act_t;                    // network, abstracted
axiom c0 : (forall (x : real, y : real) ::
              ((x >= 10.0) && (x <= 13.0)) ==> (ctrl(x, y) != up));
control { induction; check; print_results; }                  // SOUND, not bmc(N)
```

## Results

| contracts | time | verdict |
|---|---|---|
| 10 | 1.64 s | PROVED |
| 50 | 2.13 s | PROVED |
| 200 | 2.76 s | PROVED |
| 500 | 4.19 s | PROVED |
| 1000 | 6.03 s | PROVED |
| **1400** | **7.39 s** | **PROVED** |

1,400 contracts is more than NAV's 1,386. nuXmv stalled at 2,595 `TRANS`
constraints and segfaulted at 11,627.

## Validation, because near-linear scaling on quantified real axioms is suspicious

- **Property spans every contract.** Boxes are contiguous (`[10,13],[13,16],…`)
  and the invariant covers the whole span, so the proof needs all *n* axioms.
  An earlier version had disjoint boxes and a property matching `c0` alone — it
  measured parsing, not reasoning.
- **Every axiom is load-bearing.** Removing one mid-range axiom flips the result
  to `1 passed / 1 failed`.
- **Contracts are load-bearing.** Stripping all axioms makes the proof fail.
- **Non-vacuous.** Properties implied by an axiom pass; two properties not
  implied correctly fail.

## What this does NOT yet show

The plant is a toy (1-D motion, `px' = px ± 1.0`), and the contracts are
synthetic boxes rather than real CROWN output. The real test is NAV with
contracts generated by alpha-beta-CROWN against the actual network.

## Reproduce

```bash
python3 COLLAB/experiments/uclid5/gen_contracts.py COLLAB/experiments/uclid5 10 50 200 500 1000 1400
./COLLAB/experiments/uclid5/run_scaling.sh 10 50 200 500 1000 1400
```
Needs `REPRODUCIBILITY/2026_TBA/uclid5/` (source + Z3 4.12.2 via `get-z3-linux.sh`)
and a build at `uclid5/target/universal/uclid-0.9.5.zip`. The shipped 2020
prebuilt does **not** have the `real` type; an sbt build is required.
